# Formula-E-CES-TEC
Carro a escala controlado con Raspberry Pi Pico W en MicroPython: motores con L298N ( PWM ), luces con registro de corrimiento 74LS164 y encendido automático con fotorresistencia. Proyecto I, Fundamentos de Sistemas Computacionales, TEC, II Semestre 2026. Alexa Herrera Sánchez e Imanol Ovares Monge

La información más importante para el uso del código son los comandos que este utiliza, los cuales son: 

-Luces: Dir Der ( Direccional Derecha ), Dir Izq ( Direccional Izquierda ), Dir Emergencia ( Direccionales de emergencia ), Luces On ( luces frontales y traseras encendidas ), Luces Off ( Luces frontales y traseras apagadas ).

-Movimientos: Atrás, Adelante, Derecha, Izquierda, Recto, Parar.

-Velocidad: Está en escala del 0 al 100, se puede ajustar al escribir el comando y el número de la velocidad deseada.
